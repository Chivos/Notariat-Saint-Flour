- Mesures : charretée de foin (capacité d'un pré) ; seterée et cartellade (mesures agraires de Haute-Auvergne, la cartellade étant une fraction de la seterée) ; livre tournois.
- Formulaire : clause de plus-value (donation mutuelle de l'excédent de valeur, pour écarter la rescision), constitut de possession (tradition feinte), garantie d'éviction réciproque, obligation générale des biens. Coudert : pâturage commun du village.
- Abréviations : no^re = notaire ; ham^t = habitant ; parroi^e / parr^e = paroisse ; p̃ntes = présentes ; p^r = pour ; cont^t = contenant ; anth^e = Anthoine ; Bap^te = Baptiste ; p^re = Pierre ; Fran^s = François ; p̃bre = prêtre ; vj^c = six cens ; soubz^ez = soussignés.
- Pays de droit écrit (Haute-Auvergne).
